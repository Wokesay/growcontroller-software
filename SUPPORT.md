# Getting help

growcontroller is a prototype with one maintainer. There is no paid
support and no guaranteed answer time, but every question and report is
read.

| You want to … | Go to |
|---|---|
| try it | [`docs/DEMO.md`](docs/DEMO.md): download, start, a short tour, what to do when it does not start |
| find a quick answer | [`docs/FAQ.md`](docs/FAQ.md) |
| ask a question, share an idea or feedback | [Discussions](https://github.com/Wokesay/growcontroller-software/discussions) |
| report something that does not work | an issue with the [bug report form](https://github.com/Wokesay/growcontroller-software/issues/new?template=bug.yml); in the app: Settings › Report a problem |
| tell us about a device | the [device form](https://github.com/Wokesay/growcontroller-software/issues/new?template=device.yml) |
| report a vulnerability | never in public: [`SECURITY.md`](SECURITY.md) |
| contribute | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

**Before you ask:** search the open and closed issues and the
discussions, and say which version you use (Settings › Display and info)
and how you run it (simulator download, built yourself, Home Assistant
app).

**Real hardware:** the prototype is not meant to control real pumps,
valves or mains-powered devices, so we cannot help with wiring a real
setup to it yet. Questions about planned hardware are welcome in
Discussions.

Issues and discussions are public: please leave out passwords, access
tokens, Wi-Fi details and where you live.
