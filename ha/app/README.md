# Doseph

Doseph's web app for your grow, next to Home Assistant: it reads
pH, EC, temperature, humidity, CO2 and level sensors from Home Assistant
and shows them with Doseph's checks (stale, implausible, jumping
values). It switches nothing.

Experimental: a trial of the Doseph software on Home Assistant,
listed in the store only with advanced mode on in your profile. Set its
password right after the first start. See the Documentation tab and
[docs/HOME_ASSISTANT.md](https://github.com/Wokesay/doseph/blob/main/docs/HOME_ASSISTANT.md).

Used growcontroller before? Doseph replaces it, and your settings move in
a few steps: see the Documentation tab, "Coming from growcontroller".
